# حل مشكلة إظهار التوكن في GitHub

مرحباً، قمت بإعداد حل شامل لمشكلتك المتعلقة بأمان توكن بوت الديسكورد عند رفع مشروعك على GitHub. الحل يعتمد على استخدام "متغيرات البيئة" (Environment Variables) لعزل المعلومات الحساسة عن الكود المصدري.

## لماذا هذا الحل مهم؟

عندما يكون التوكن الخاص بالبوت (مثل `DISCORD_BOT_TOKEN`) مكتوباً مباشرة في الكود، يمكن لأي شخص يطلع على مشروعك على GitHub أن يراه. هذا يمثل خطراً أمنياً كبيراً، حيث يمكن لأي شخص استخدام هذا التوكن للتحكم في البوت الخاص بك، وإرسال رسائل باسمه، أو حتى إساءة استخدامه بشكل قد يؤدي إلى حظر حسابك من ديسكورد.

## كيف يعمل الحل؟

الحل يتكون من عدة أجزاء تعمل معاً لحماية التوكن:

1.  **ملف `.env`**: هو ملف بسيط تضع فيه المعلومات الحساسة (مثل التوكن) على شكل `KEY=VALUE`. هذا الملف **لن يتم رفعه** إلى GitHub.

2.  **مكتبة `dotenv`**: هي مكتبة بسيطة في Node.js تقوم بقراءة المتغيرات من ملف `.env` وتحميلها في بيئة التشغيل (`process.env`)، مما يجعلها متاحة للاستخدام في الكود الخاص بك دون الحاجة لكتابتها مباشرة.

3.  **ملف `.gitignore`**: هو ملف خاص بـ Git يخبره بتجاهل ملفات ومجلدات معينة. لقد أضفنا `.env` إلى هذا الملف لضمان عدم رفعه إلى GitHub عن طريق الخطأ.

4.  **تعديل `main.js`**: تم تعديل الكود ليقوم باستدعاء التوكن من `process.env.DISCORD_BOT_TOKEN` بدلاً من كتابته مباشرة.

5.  **تعديل `package.json`**: تم إضافة `dotenv` إلى الاعتماديات، والأهم من ذلك، تم تعديل إعدادات `electron-builder` ليقوم بتضمين ملف `.env` داخل التطبيق النهائي عند عمل `build`. هذا يضمن أن التطبيق سيعمل عند المستخدمين النهائيين.

## الخطوات المطلوبة لتطبيق الحل

لتطبيق هذا الحل في مشروعك، اتبع الخطوات التالية بدقة:

### الخطوة الأولى: إضافة ملف `.gitignore`

إذا لم يكن لديك ملف `.gitignore` في مشروعك، قم بإنشاء ملف جديد بهذا الاسم في المجلد الرئيسي للمشروع والصق فيه المحتوى الموجود في ملف `.gitignore` المرفق. هذا الملف سيمنع رفع الملفات الحساسة والمجلدات غير الضرورية إلى GitHub.

### الخطوة الثانية: إنشاء ملف `.env`

1.  قم بإنشاء ملف جديد باسم `.env` في المجلد الرئيسي لمشروعك.
2.  افتح الملف والصق فيه المحتوى التالي، مع استبدال القيم بالمعلومات الصحيحة الخاصة بك:

    ```text
    DISCORD_BOT_TOKEN=your_actual_bot_token_here
    DISCORD_CHANNEL_ID=your_actual_channel_id_here
    ```

    **مهم جداً**: لا تشارك هذا الملف مع أي شخص واحذر من رفعه إلى GitHub.

### الخطوة الثالثة: تحديث `package.json`

قم بنسخ محتوى ملف `package.json` المرفق واستبدل به محتوى الملف الموجود لديك. التغييرات الرئيسية هي:

*   إضافة `"dotenv": "^16.4.5"` ضمن `dependencies`.
*   إضافة قسم `extraFiles` ضمن `build` لضمان تضمين ملف `.env` في النسخة النهائية من التطبيق.

### الخطوة الرابعة: تحديث `main.js`

قم بنسخ محتوى ملف `main.js` المرفق واستبدل به محتوى الملف الموجود لديك. الكود الجديد يقوم بتحميل التوكن بأمان من ملف `.env`.

### الخطوة الخامسة: تثبيت الاعتماديات

افتح الطرفية (Terminal) في مجلد مشروعك وقم بتشغيل الأمر التالي لتثبيت مكتبة `dotenv`:

```bash
npm install
```

## النتيجة النهائية

بعد تطبيق هذه الخطوات، سيكون مشروعك جاهزاً للرفع على GitHub بأمان. التوكن الخاص بك سيبقى محفوظاً في ملف `.env` على جهازك المحلي فقط، ولن يظهر أبداً في الكود المصدري على GitHub. عند عمل `build` للتطبيق، سيتم تضمين ملف `.env` داخل حزمة التطبيق النهائية ليتمكن من العمل بشكل صحيح عند المستخدمين.

لقد أرفقت لك جميع الملفات المعدلة لتسهيل العملية عليك.
